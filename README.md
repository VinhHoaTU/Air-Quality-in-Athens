# 🌍 Air Quality in Athens
This project aims to predict ozone levels using historical data and additional features such as NO₂ concentration, temperature, wind speed, and others. We apply machine learning and deep learning models both directly on the data and on the residuals to better capture trends and seasonality. Additionally, we implement online learning and expert aggregation techniques to enhance predictive performance.

# Models:
Linear regression, Penalized regression, Dicision tree, Random forest, grandient boosting, multilayer perception, RNN, GRU, LSTM, expert agregation ED, EWA.
